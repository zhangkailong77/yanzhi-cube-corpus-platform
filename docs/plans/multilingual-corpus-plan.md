# 多语言语料库建设规划方案

## 一、总体策略
- **源语言策略**：多语言并行创作，然后进行语料对齐
- **推进方式**：按类别逐层推进（6个阶段）
- **内容获取**：中英文专业内容 + 泰/马/越AI生成
- **质量策略**：渐进式（快速上线→持续优化）

---

**预计周期**：3-4周

| 语言 | 数量目标 | 获取方式 | 优先级 |

| 马来语 | 200对 | AI生成+校对 | P1 |
| 越南语 | 200对 | AI生成+校对 | P1 |

**问答分类**：
- 基础概念（30%）：什么是...
- 流程操作（40%）：如何办理...
- 规则政策（20%）：XX规定是什么...
- 风险防范（10%）：如何避免...

**语料示例**：
```
中文：
问题：跨境贸易中的DDP和DDI条款有什么区别？
答案：DDP（完税后交货）指卖方负责办理进口清关手续并支付进口税费，货物送达指定地点交付买方；DDI（未完税交货）指卖方将货物运至目的地，但买方负责进口清关和税费支付。DDP对卖方责任更大。

English:
Question: What is the difference between DDP and DDI terms in cross-border trade?
Answer: DDP (Delivered Duty Paid) means the seller is responsible for import clearance and pays import duties, delivering goods to the specified location for the buyer. DDI (Delivered Duty Unpaid) means the seller transports goods to the destination, but the buyer handles import clearance and pays duties. DDP places greater responsibility on the seller.
```

## 三、渐进式质量控制方案

### 阶段1-2（快速上线期）
- **质量目标**：可用即可
- **验证方式**：抽样人工检查（10%）

- **质量目标**：准确率80%+

- **标准**：术语准确，表达自然，符合业务逻辑

- **质量目标**：准确率90%+，用户满意度85%+
- **验证方式**：专家审核（30%）+ 用户反馈迭代
- **标准**：高质量、本地化、实战性强

## 四、技术实施建议

### 1. AI生成策略（泰/马/越）

**Prompt模板**：
```
作为跨境贸易专家，请生成[语言]的[类别]内容。
要求：专业术语准确、表达地道、符合当地法规。
参考示例：[提供中英文示例]
```

**生成流程**：
1. 准备中英文高质量示例作为few-shot
2. 设计针对性prompt
3. 批量生成初稿
4. 自动质量检测（术语准确度、长度、格式）
5. 人工抽检（初期20%，后期10%）

### 2. 语料对齐方法

**基于语义对齐**：
- 使用embedding模型（如text-embedding-ada-002）计算相似度
- 设定相似度阈值（>0.85为高质量对齐）
- 低质量对齐人工复核

**基于结构对齐**：
- 相同字段结构强制对齐（如术语名、定义、例句）
- 建立结构化模板
- 自动填充+人工校准

**基于人工校准**：
- 关键语料（10%核心内容）人工复核
- 建立对齐规则库
- 持续优化对齐算法

### 3. 版本管理

```
v1.0：基础版本（阶段1-2完成）
  - 术语库完整
  - 问答库可用
  - 多语对齐基础完成

v2.0：增强版本（阶段3-4完成）
  - 流程规则完整
  - 案例库充实
  - 多语对齐全面覆盖

v3.0：完善版本（阶段5-6完成）
  - 指令生成完整
  - 全面质量优化
  - 用户反馈迭代
```

## 十、总结

这个规划方案的核心优势：

1. **渐进式**：从简单到复杂，降低风险
2. **按类推进**：每个阶段产出可用成果
3. **质量可控**：从快速上线到持续优化
4. **多语言并行**：满足东南亚市场需求
5. **灵活调整**：每个阶段独立验收，可灵活调整

**预计总周期**：17-23周（约4-6个月）

**建议启动时间**：立即启动阶段1（术语类）

**优先交付目标**：
- 3个月内完成阶段1-2，交付基础语料库
- 6个月内完成全部6个阶段，交付完整语料库
